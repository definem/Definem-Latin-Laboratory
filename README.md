# Lotincha lugʻat testi

Tibbiyot lotin tili soʻzlarini yodlash uchun kichik test sayti. Lotincha soʻz chiqadi, toʻrtta oʻzbekcha variantdan toʻgʻrisini tanlaysiz, oxirida natija koʻrsatiladi. Natijalar har bir foydalanuvchining oʻz brauzerida (localStorage) saqlanadi, backend kerak emas.

## Fayllar

- `index.html` — sahifa va test mantigʻi
- `words.js` — lugʻat (yangi soʻzlar shu yerga qoʻshiladi)

## Yangi soʻz qoʻshish

`words.js` ichidagi roʻyxatga yangi qator qoʻshing:

```js
["lotincha", "grammatika (boʻlmasa boʻsh qoldiring)", "oʻzbekcha"],
```

Bir xil lotincha soʻz ikki marta yozilib qolsa, sayt faqat birinchisini oladi.
